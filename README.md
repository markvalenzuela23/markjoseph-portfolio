## Development

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm run build   # production build to dist/
npm run preview # preview the production build
npm run lint    # run ESLint
npm run deploy  # build and publish dist/ to GitHub Pages
```

> **Note:** the site is served from the `/markjoseph-portfolio/` subpath on
> GitHub Pages. Link to files in `public/` with `import.meta.env.BASE_URL`
> (see `resumeUrl` in `src/data/profile.js`) rather than a root-absolute path,
> or they will 404 in production.
